常见错误

        症状 → 原因 → 处理
      

      

        

          

            
              

                症状
                原因
                处理
              

            
            
              

                Claude Code 里请求打不通，地址像是多了一层
                API 地址后面多加了 /v1 后缀
                
                  地址写成
                  /{渠道}
                  （例如 /warp），
                  不要添加 /v1 后缀。
                
              

              

                Grok 请求落到别的路由上
                把 Grok 当成了与其他渠道不同的写法
                
                  Grok 与其他渠道保持一致，使用 /grok/v1 前缀。
                
              

              

                Puter 账号保存时报缺凭据或字段不对
                按其他渠道的习惯填了多余字段
                
                  Puter 账号当前只需要填写 auth_token。
                
              

              

                WorkBuddy 无法新增账号，或保存后不可用
                该渠道不提供手填凭证，手填无法生效
                
                  在账号页面手动点击「使用 WorkBuddy 官方网页登录」，在官方页面完成授权后账号会自动保存，
                  服务端不接触密码；编辑已有账号时也可用它重新授权。批量导入仍可通过 API 使用会话
                  refreshToken。
                
              

              

                模型列表里找不到 openrouter:、togetherai: 这类模型
                聚合源前缀模型暂时不直接暴露到模型管理里
                
                  使用 Puter 的“无前缀主模型”清单，已包含 Claude / OpenAI / Gemini / Grok / DeepSeek /
                  Mistral 等主模型族。
