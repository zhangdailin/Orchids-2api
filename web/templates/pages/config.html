缓存

Token

Prompt 前缀缓存降低上游 token 消耗，常驻内存随 TTL 与 QPS 线性增长。

按 System / Tools 前缀复用上游 prompt 计算结果，关闭后每次请求都完整走上游。
开：命中即跳过上游计算
TTL 越长命中率越高，常驻内存也越大；推荐 5–30 分钟。
分离缓存把 System 与 Tools 分开存放，命中率更稳。
内存估算

估算口径：QPS × TTL × 0.5KB × 策略系数，括号内为当前生效参数。

10 QPS · 推荐区间
~1.5MB
低并发，TTL ≤ 30 分钟时内存可忽略
50 QPS · 常见区间
~7.5MB
建议 TTL 不超过 1 小时
100 QPS · 需关注
~15MB
TTL 超过 1 小时后增速最快
TTL: 300s 系数: × 2 推荐 TTL: 5–30 分钟

数值过高说明 TTL 或 QPS 估计偏大：100 QPS + TTL 1 周 + ×2 系数时估算内存可达数 GB。 建议先按 5–30 分钟 TTL 观察命中率，再逐步调大。
