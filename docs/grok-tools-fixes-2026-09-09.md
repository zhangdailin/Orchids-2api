# Grok 工具页修复记录

## 实现

- 去掉按消息数删除历史的逻辑。旧版本已经删除的历史无法自动恢复。
- 正文与思考按独立流字段累计、持久化和重绘；迁移旧的单段、多段及部分拆分历史。
- 流错误、意外 EOF 和主动停止时保存已收到的部分内容；无内容的失败不伪造 assistant 历史。
- 相同提问的编辑按选中的消息行定位；请求中禁止切换、新建和删除会话。
- 展示函数调用和 Web/X 搜索状态，后端补 X 搜索事件透传。
- 模型列表返回持久化的 capabilities、provider 和 upstream_model；页面依据这些字段选择聊天、媒体模型。
- Build Chat 的摘要默认 auto；保留调用者 effort，不自动降级。固定推理模型的选项受控；线上确认 Grok 4.6 不支持 none，页面禁用并提示旧会话的不支持设置。
- 回放密文增加 Base64、大小、最小长度和熵校验；清除、读取、保存的持久化操作串行化。
- 识别的解码400按去密文、保留可读摘要、安全重置会话恢复。遇真实 compaction 不改写；previous_response_id 阻止会话重置；429 不再重复恢复。每个恢复阶段记录开始时间、耗时、阶段和次数。
- 图片保留连续生成，增加模型、每批数量及显式模型的1k/2k选项。
- 视频依路由提供生成、编辑、延长、首帧或参考图片/音色。1080p仅对符合后端限制的Console模型开放；编辑/延长不发送不支持的分辨率字段。
- 实时语音继续保留，另增加TTS/STT入口、语言、音色/语速、文件上传、播放下载及转写结果。

## 边界

媒体操作已接入既有后端并验证请求字段，未逐项进行付费图片、视频、语音生成验收，也未进行完整浏览器视觉验收。具体可用性仍取决于所选提供方、账号和额度。历史裁切前已丢失的数据不可恢复。

本轮修复不等于整个项目与最新 grok2api 协议实现完全等价；上游新增多轮工具调用 reasoning 桥接仍需独立场景验证。原生 Responses/compact 透传、客户端 effort 所有权等原有策略保留。
