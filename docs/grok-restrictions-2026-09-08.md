## 补充修复

复核发现 HTTP 总超时配置还会被两处更短边界覆盖，因此同步调整：

- Grok 使用独立缓存键的 HTTP 客户端，不再继承通用客户端 HTTP/1 响应头最多 120 秒的启发式上限；响应头等待仍受 HTTP 总超时约束。其他通道继续使用原有策略。
- 托管 egress 的客户端总超时不再固定 120 秒，改为使用对应 provider 配置。
- Web 图片编辑移除旧 imageEditModelConfig、无用 parent post 创建和 URL 收集逻辑，统一到 metadata ID + imageToImage payload；保留已有自定义指令等配置语义。
- Web 工具历史文本化时保留图片块，避免已放开的 tool/assistant 图片在后续适配阶段丢失。
